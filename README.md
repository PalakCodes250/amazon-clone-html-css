# Amazon Clone

A front-end clone of the Amazon website built using **HTML** and **CSS**. This project focuses on recreating the layout and design of a modern e-commerce platform while improving front-end development skills and responsive web design.

## Features

- Amazon-inspired homepage design  
- Navigation bar with logo, search bar, and menu options  
- Product category sections with images  
- Hero banner section  
- Product cards and grid layout  
- Footer section similar to Amazon  
- Responsive and clean user interface

## Technologies Used

- HTML5  
- CSS3

## Project Purpose

This project was created to practice:

- Front-end web development  
- Website layout structuring using HTML  
- Styling and responsiveness using CSS  
- Building real-world UI clones for learning purposes

## How to Run the Project

1. Download or clone the repository  
2. Open the project folder  
3. Run `index.html` in any web browser
